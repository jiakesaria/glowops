# Prototype example outputs

`live_candidate.json` was generated by the assigned Foundry deployment and screened by
the checker and pinned Jev model on October 14, 2026. The final decision was **revise**:
the checker proposed proceed while Jev proposed revise. The ledger preserves the source
reference, extension rationale, both assessments and the final decision. This is a real
prototype output, not a verified scientific finding. Human review remains necessary;
in particular, check the consistency of the proposed years and the claims about the paper.

`fake_candidate.json` and `fake_evaluation.json` were produced in fake mode. They are
connection examples, not live model performance. The fake checker always returns proceed.

To run from the repository root:

```sh
python smoke_test.py
python generate.py --count 1 --paper-id braithwaite_2011
python run_tests.py --with-jev
```

For offline reproduction with no keys:

```sh
python generate.py --fake --count 1
python run_tests.py --fake
python run_rounds.py --fake
```

The three-round chart appears at `results/accuracy_by_round.png`. Runtime outputs remain
local under `results/` and `data/*ledger.jsonl`; review them before sharing.
